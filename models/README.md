# Pose model

Place `pose_landmarker_full.task` here. The configured adapter uses the MediaPipe Tasks Pose Landmarker in VIDEO mode.

Official model and setup documentation: https://ai.google.dev/edge/mediapipe/solutions/vision/pose_landmarker/python

Record the downloaded file's SHA-256 in each analysis provenance sidecar. The analyzer computes it automatically; model weights are intentionally ignored by Git.
